# Speedrun Ethereum: Tokenization (Challenge 0)

## 1. Introduction

This repository is a **Speedrun Ethereum** challenge focusing on **Tokenization**. It provides a full-stack NFT minting and transferring dApp built on top of **Scaffold-ETH 2**.

- **Smart Contracts (`packages/hardhat`)**: ERC-721 token (`YourCollectible.sol`) utilizing OpenZeppelin contracts with Enumerable and URIStorage extensions.
- **Frontend (`packages/nextjs`)**: Next.js App Router, RainbowKit, Wagmi, Viem, Tailwind CSS, and DaisyUI.
- **IPFS Integration**: Seamless metadata pinning and fetching via Speedrun Ethereum's IPFS proxy service.

---

## 2. Quick Start

### Prerequisites
- [Node.js](https://nodejs.org/) (>= v22.10.0)
- [Yarn](https://yarnpkg.com/) (v4.x included via `.yarn/releases`)

### Getting Started

Run each command in a separate terminal:

1. **Install dependencies:**
   ```bash
   yarn install
   ```

2. **Start the local blockchain:**
   ```bash
   yarn chain
   ```

3. **Deploy contracts locally:**
   ```bash
   yarn deploy
   ```

4. **Launch the frontend:**
   ```bash
   yarn start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view and interact with your dApp.

5. **Run test suite:**
   ```bash
   yarn test
   ```

## 3. Notes

- **Contract ABIs**: Auto-generated in `packages/nextjs/contracts/deployedContracts.ts` after running `yarn deploy`. Do not edit this file manually.
- **IPFS Service**: IPFS uploads and reads are routed through Next.js API routes (`/api/ipfs/*`). The frontend server (`yarn start`) must be running for IPFS operations to succeed.
- **AI Agent Guidance**: Agent guidelines, challenge specifications, and modular skills are centralized in [`AGENTS.md`](./AGENTS.md) and the [`.agents/`](./.agents/) directory.
- **Testnet Deployment**: To deploy to Sepolia or another testnet, set your deployer account (`yarn generate`), fund it with faucet ETH, configure `hardhat.config.ts` / `scaffold.config.ts`, and run `yarn deploy --network sepolia`.
